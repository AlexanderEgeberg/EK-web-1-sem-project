## Get started
### Database
Åbn pgAdmin og opret en database f.eks `festival`
Lav en kopi af og kald den .env [.env.example](/backend/.env.example)
Udfyld `<DB_VARIABLER>` i .env `DATABASE_URL`

### Backend
Fra projekt mappe:
`cd backend`
`npm install`
`npm run db:reset` loader [festival.sql](/database/festival.sql)
Nu er backend + database sat op

`npm run dev` starter serveren med connection til database
